# Boundary Lab 0.4.4

Maintenance release from the 0.4.3 stable codebase. No new solver or application
features are included.

The Windows updater now installs the latest published stable GitHub release in a
detached checkout, rather than pulling the development branch. It refuses dirty
tracked files, unpublished commits and feature branches, and never falls back to
main if release lookup fails. Existing development branches remain available.

Before updating an older installation, replace its updater with the
01_install_update_boundary-lab.bat asset from this release. Old updater copies
still pull main and cannot be remotely changed. Alternatively, extract the
stable source archive into a separate folder. Stable users should not use the
main branch ZIP. Developers should follow docs/development.md.

BEAT Engine remains pinned to the previously tested 0.1.4 wheel.
