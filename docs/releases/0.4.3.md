# Boundary Lab 0.4.3

- Move the numerical runtime into the separately released BEAT Engine package,
  with a pinned wheel and SHA-256, worker contract negotiation, and reproducible
  engine provenance. This release uses BEAT Engine 0.1.4.
- Add remote solver connections and a server with backend selection, authentication,
  TLS support, and container build tooling.
- Improve mesh interface stitching and automatic reload behavior; fix omitted
  quadratic FEM boundary triangles and chamber diaphragm-area handling.
- Add FEM result plotting, particle-velocity plots, and input-power plots.
- Improve Deploy comparison and impedance plots, ground-plane handling, and
  plot visibility.
- Standardize the positive-time phasor convention and expose engine-owned backend
  capabilities.
- Improve UI caching, loading feedback, light-theme colors, documentation, and
  the splash image; fix failures on repeated solves.
- Apply Ruff linting and formatting across the Python application and tests.

CI checks Python lint, formatting, and tests, then validates and solves a
physical project using the pinned published engine package.
