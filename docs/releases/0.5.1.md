# Boundary Lab 0.5.1

Save a project and its solved results together in a portable `.blab` file.
Select the solved-results option in **Save As** to reopen plots and adjust
channel gain, delay, and crossovers without running the solve again.
Existing `.blab.json` projects still open.

## Design and solve setup

- Choose a generator plugin when adding a design with the **+** beside the design tabs.
- Use **Edit → Project Configuration** for observation sampling and plot presentation.
  Application-wide settings remain under **Preferences**.
- Toggle **Impose Channel Normalization** in channel configuration after solving.
  New projects start with normalization off, exterior mesh stitching on, and
  fractional-octave smoothing off. New installations start with the light theme.
- Set both frequency limits on one range slider. The status bar shows BEM and
  FEM pressure unknowns for active meshes, and solve progress includes a time estimate.
- Select a boundary row to outline its surface in the 3D viewport. Rotate
  observation planes using axis handles with an angular scale.

## Results and solver changes

- Inspect acoustic flow arrows and particle velocity in field views, select
  individual channels in polar isobar plots, and read one-way peak excursion.
- Query saved results and generate plots and observation-plane reports from the CLI.
- Use axial prescribed-velocity sources in coupled projects. The release pins
  BEAT Engine 0.9.0 and includes fixes for interface seams at cabinet edges and
  imported driver reference metadata.
