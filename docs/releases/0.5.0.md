# Boundary Lab 0.5.0

Boundary Lab 0.5.0 expands geometry generation, coupled-model diagnostics and
desktop packaging since 0.4.4.

## Geometry and model editing

- Add geometry-provider plugins, transactional multi-mesh assemblies and a
  bundled parametric vented-enclosure generator.
- Detect and repair near-coincident mesh vertices before solving.
- Add interface geometry measurements and persistent construction diagnostics,
  and improve planar interface surrounding-surface selection.
- Add axial prescribed sources with motion-direction previews and correct
  diaphragm area for opposing sides in one acoustic region.
- Add an optional thermoviscous wall-loss setting for supported FEM regions.
- Import and export generic driver text from the component editor.

## Results and desktop experience

- Plot separate radiated SPL contributions from coupled interfaces.
- Export selected traces and simplify docked plot titles.
- Add layout reset and screen-bounded error dialogs with a copy button.
- Suppress Windows consoles for background geometry and solver processes.
- Add standalone Windows CPU/CUDA installer tooling and signed macOS Apple
  Silicon packaging with CPU/Metal solvers. Installer publication requires
  separate qualification of the actual packaged artifacts.
- Document optional external Ath/Wine setup on macOS.

## Compatibility

The embedded Deploy application has moved to the separate Boundary Lab Deploy
repository. Boundary Lab retains speaker-package export.

The pinned engine dependency is BEAT 0.6.0. Its projected FEM-BEM interface
correction changes numerical results and rejects rank-deficient or poorly
conditioned interface triangulations. Recompute affected results and verify
mesh convergence. Worker and result schema versions remain unchanged.

## Known CUDA precision limitation

The Vented_Sub fixture's 50 Hz voice-coil current differs by 0.134% between
CPU and CUDA (about 86 microamps), exceeding the 0.1% backend-agreement screen.
The same comparison in BEAT 0.5.1 differs by 0.135%, so this is an existing
limitation rather than a regression introduced by BEAT 0.6.0.

Against the double-precision CPU reference, the 0.6.0 current errors at 50 Hz
are 0.011% for production CPU and 0.145% for CUDA. Use CPU when this low-current
accuracy matters. The other 20 quantity/frequency comparisons at 50, 100 and
200 Hz pass the 0.1% screen. These checks do not establish mesh convergence or
accuracy for other models and frequencies; the failed comparison remains part
of the qualification record.
