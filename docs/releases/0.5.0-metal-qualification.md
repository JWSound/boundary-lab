# BEAT 0.6.0 final-wheel Metal qualification

Run on an Apple Silicon Mac with Julia 1.12.6, Python 3.11+ and an authenticated
GitHub CLI. These commands require the **draft v0.6.0 release to exist** after
BEAT's release PR and exact main-commit CI pass. Do not substitute the local
preparation wheel or an editable checkout.

Use a new directory. The shell stops on failure and retains each test log.

```sh
set -euo pipefail
mkdir beat-0.6.0-qualification
cd beat-0.6.0-qualification
gh release download v0.6.0 --repo JWSound/BEAT_Engine \
  --pattern 'beat_engine-0.6.0*' --pattern SHA256SUMS.txt
shasum -a 256 -c SHA256SUMS.txt
sw_vers > hardware.txt
system_profiler SPHardwareDataType SPDisplaysDataType >> hardware.txt
julia --version >> hardware.txt
python3 -m venv .venv
source .venv/bin/activate
python -m pip install ./beat_engine-0.6.0-py3-none-any.whl
python -m beat_engine instantiate --backend metal 2>&1 | tee instantiate-metal.log
python -m beat_engine doctor --backend metal --threads 2 > doctor-metal.json
python -c 'import json; d=json.load(open("doctor-metal.json")); assert d["backends"]["metal"]["available"], d'
ENGINE_ROOT="$(python -c 'from beat_engine import engine_paths; print(engine_paths("metal").root)')"
export BLAB_RUN_COUPLED_METAL=1
export BLAB_COUPLED_FEM_SOLVER=umfpack
for test in runtests metal_host_tests metal_near_correction_tests \
  metal_kernel_coverage_tests metal_coupled_precompile_coverage_tests \
  field_output_batch_tests compiled_metal_worker_tests
do
  julia --threads=2 --startup-file=no --project="$ENGINE_ROOT/julia_metal" \
    "$ENGINE_ROOT/julia_local/tests/$test.jl" 2>&1 | tee "$test.log"
done
```

The device-availability assertion is required: a skipped GPU test is not a
qualification pass. Preserve failures without loosening tolerances or changing
fixtures. Return `SHA256SUMS.txt`, `hardware.txt`, `doctor-metal.json` and the
logs. Hardware inventories can include a serial number; redact that before
sharing publicly.

This qualifies the engine wheel's Metal paths. It does not qualify the signed
Boundary Lab app/DMG. After the app adopts the published engine wheel, follow
[macOS installer qualification](../macos-installer.md) for the final installer,
including actual CPU/Metal solves, signatures and notarization.
